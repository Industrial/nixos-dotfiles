If you are considering contributing to QuestieTrace please be aware that submitting pull requests after 21.10.2026 will be counted as consent for licensing your contribution under the GPLv3 license.

## Third party software licensing

The libraries in the `Libs` directory are third-party-software and their individual licenses apply.

## Other licensing

1. License information inside an individual file
