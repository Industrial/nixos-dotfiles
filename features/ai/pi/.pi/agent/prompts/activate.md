argument-hint: []

1. **Context7**: Run the Pi command `mcp connect context7`.
2. **Serena:**: Run the Pi command `mcp connect serena`, then call MCP tool **`activate_project`** for this repo when the session begins.
3. **Roam:**: Run the Pi command `mcp connect roam-code`, then run the CLI program `roam health` to verify codebase index.
4. **LeanCTX**: Run the Pi command `mcp connect lean-ctx`, then run the CLI program `lean-ctx cheatsheet`.
5. **MCP Debugger**: Run the Pi command `mcp connect mcp-debugger`.
6. **Beads**: Run the CLI program `bd prime`.
7. **GitHub CLI**: Use the `gh` cli for GitHub when needed.
