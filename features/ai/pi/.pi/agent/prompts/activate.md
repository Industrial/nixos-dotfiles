1. **Context7**: Run `mcp connect context7`.
2. **Serena:**: Run `mcp connect serena`, then call MCP tool **`activate_project`** for this repo when the session begins.
3. **Roam:**: Run `mcp connect roam-code`, then run `roam health` to verify codebase index.
4. **LeanCTX**: Run `mcp connect lean-ctx`, then run `lean-ctx cheatsheet`.
5. **MCP Debugger**: Run `mcp connect mcp-debugger`.
6. **Beads**: Run `bd prime`.
7. **GitHub CLI**: Use the `gh` cli for GitHub when needed.
